# Github-user-finder
Создание приложения поиск пользователей Github
Автор Давлятов Тимур
## Как использовать API
1. Приложение использует `https://api.github.com/search/users?q={query}` для поиска.
2. Не требует токена для базовых запросов (ограничение — 60 запросов в час).

## Как использовать приложение
1. Запустите `github_user_finder.py`.
2. Введите имя пользователя в поле поиска.
3. Нажмите «Поиск» для отображения результатов.
4. Выберите пользователя из списка и нажмите «Добавить в избранное».
5. Избранные пользователи отображаются в нижней части окна.

## Примеры использования
- Поиск пользователя: введите `octocat` и нажмите «Поиск».
- Добавление в избранное: выберите `octocat` из списка и нажмите «Добавить в избранное».
- Просмотр избранных: список избранных пользователей обновляется автоматически.

## Требования
- Python 3.6+
- Библиотеки: `tkinter`, `requests`
